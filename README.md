# Questão 10 - Replicação de Página Web com CSS

## Descrição
Atividade do Módulo 04 de CSS do curso Alpha EdTech.

Replicação da página de busca do Pinterest (https://br.pinterest.com/search/pins/?q=páginas%20web) utilizando HTML e CSS, sem o uso de flexbox ou grid.

## Modelo escolhido
Pinterest - Página de resultados de busca por "páginas web"

## Condições da atividade
- Não foi utilizado flexbox ou grid
- Foram utilizadas propriedades de posicionamento CSS
- As imagens foram selecionadas para se encaixar no modelo

## Propriedades de posicionamento utilizadas
- `position: fixed` — sidebar de navegação
- `position: absolute` — botões dentro do campo de busca e tempo nos frames de vídeo
- `position: relative` — campo de busca e `.video-frame` (div que envolve a imagem PNG simulando frame de vídeo, permitindo o `span` com o tempo ficar posicionado sobre ela)
- `float: left` — layout de colunas da galeria de cards

## Tecnologias utilizadas
- HTML5
- CSS3
- Font Awesome 6.5.0 (ícones do sidebar)

## Como visualizar
Abra o arquivo `index.html` no navegador ou acesse pelo GitHub Pages.
